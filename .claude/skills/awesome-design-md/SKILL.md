# Awesome DESIGN.md (VoltAgent)

Source: https://github.com/VoltAgent/awesome-design-md (MIT).

Each folder in `design-md/<brand>/DESIGN.md` is a plain-text design system: palette tokens, typography scale,
spacing, radii, component rules and do/don't lists, analysed from the brand's real website.

## How to use
1. List `design-md/` and pick 1-3 references whose *discipline* fits the brief (not their look).
2. Read the chosen DESIGN.md files fully.
3. Borrow system rigor (type scale, spacing rhythm, colour roles, component consistency), never clone a brand's identity.
4. Write the project's own DESIGN.md describing the system you actually built.
